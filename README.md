 🤖 AI Receptionist

An AI receptionist that picks up calls and DMs for you. It handles FAQs, takes messages, and flags anything urgent straight to you.

> Built as **Project 01** of the [ai.veerse](https://instagram.com/ai.veerse) series.

## ✨ What it does

- 📞 **Answers phone calls and DMs** (WhatsApp / Instagram / web chat)
- ❓ **Handles FAQs automatically** (hours, prices, location, services)
- 📝 **Takes messages** with the caller's name and contact number
- 🚩 **Flags urgent matters** and alerts the owner instantly
- 📊 **Dashboard** showing calls today, DMs replied, and urgent flagged
